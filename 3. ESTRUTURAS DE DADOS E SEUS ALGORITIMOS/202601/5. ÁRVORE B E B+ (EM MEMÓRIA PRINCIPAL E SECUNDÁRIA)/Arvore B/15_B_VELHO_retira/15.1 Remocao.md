Com base no material fornecido, a operação de remoção (retirada) em uma Árvore B é projetada para ser realizada em **uma única passagem** de cima para baixo. Para garantir isso sem violar as propriedades da árvore, o algoritmo exige que, ao descermos para um nó, ele possua pelo menos $t$ chaves (uma a mais que o mínimo permitido, $t-1$).

Abaixo estão descritos e resolvidos, passo a passo, todos os exemplos práticos de remoção apresentados no documento.

---

## Árvore Inicial de Referência

Para os primeiros casos, utilizaremos a árvore original apresentada no PDF:

```text
               [ P ]
             /       \
     [ C, G, M ]       [ T, X ]
     /   |   |   \     /   |   \
[A,B] [D,E,F] [J,K,L] [N,O] [Q,R,S] [U,V] [Y,Z]

```

(Nota: Pelos nós da árvore, podemos deduzir que o grau mínimo é $t = 3$, o que significa que cada nó deve ter pelo menos $t-1 = 2$ chaves, exceto a raiz ).

---

## CASO 1: Remoção em Nó Folha

> 
> **Regra:** Se a chave $k$ está no nó $x$ e $x$ é uma folha, basta eliminar $k$ diretamente de $x$.
> 
> 

Exemplo: Remoção da chave `F` 

* **Passo a passo:** 1. O algoritmo desce a árvore procurando pela chave `F`.
2. Ele localiza `F` no nó folha `[D, E, F]`.
3. Como o nó possui 3 chaves (`[D, E, F]`), remover uma chave não violará o limite mínimo de $t-1=2$ chaves.
4. `F` é eliminado diretamente.



**Resultado:**

```text
               [ P ]
             /       \
     [ C, G, M ]       [ T, X ]
     /   |   |   \     /   |   \
[A,B]  [D,E]  [J,K,L] [N,O] [Q,R,S] [U,V] [Y,Z]

```

---

## CASO 2A: Nó Interno (Predecessor Forte)

> **Regra:** Se a chave $k$ está em um nó interno $x$, e o filho esquerdo $y$ (que precede $k$) tem pelo menos $t$ chaves, encontramos o **predecessor** $k'$ de $k$ (a maior chave na subárvore de $y$). Removemos recursivamente $k'$ e substituímos $k$ por $k'$ em $x$.
> 
> 

Exemplo: Remoção da chave `M` 

*Estado anterior: Árvore após a remoção de `F`.*

* **Passo a passo:**
1. A chave `M` está no nó interno `[C, G, M]`.


2. O algoritmo olha para o filho à esquerda de `M`, que é o nó `[J, K, L]`.


3. Esse filho tem 3 chaves (cumpre o requisito de ter "ao menos $t$" chaves).


4. O **predecessor** de `M` é a maior chave desse nó, ou seja, `L`.
5. O algoritmo elimina `L` de sua posição original de forma recursiva e o coloca no lugar de `M`.





**Resultado:**

```text
               [ P ]
             /       \
     [ C, G, L ]       [ T, X ]
     /   |   |   \     /   |   \
[A,B]  [D,E]  [J,K]  [N,O] [Q,R,S] [U,V] [Y,Z]

```

---

## CASO 2B: Nó Interno (Sucessor)


O **Caso 2B** é o "gêmeo simétrico" do Caso 2A. Ambos tratam da remoção de uma chave que está dentro de um **nó interno**, mas eles olham para lados opostos para decidir quem vai substituir a chave removida:

* **Caso 2A (Predecessor / Olhar para a Esquerda):** Se o filho imediatamente à **esquerda** da chave que você quer remover tiver chaves suficientes ($\ge t$), o algoritmo desce por ele, encontra o seu **predecessor** (a maior chave daquela subárvore esquerda), remove-o e o coloca no lugar da chave deletada.
* **Caso 2B (Sucessor / Olhar para a Direita):** Se o filho da esquerda estiver no limite mínimo ($t-1$), mas o filho imediatamente à **direita** tiver chaves suficientes ($\ge t$), o algoritmo faz o inverso: desce por ele, encontra o seu **sucessor** (a menor chave daquela subárvore direita), remove-o e o promove para o lugar da chave deletada.

**Em resumo:** Enquanto o **2A** rouba a maior chave do lado **esquerdo**, o **2B** rouba a menor chave do lado **direito**. O algoritmo só recorre ao Caso 2B se o filho da esquerda não puder ceder chaves, priorizando sempre manter os nós internos balanceados sem precisar fundi-los (Caso 2C).

---

## CASO 2C: Nó Interno com Filhos sem Chaves Extras (Intercalação)

> **Regra:** Se a chave $k$ está em um nó interno $x$, e tanto o filho à esquerda $y$ quanto o filho à direita $z$ possuem apenas o mínimo de chaves ($t-1$), junta-se ($intercala$-se) a chave $k$ e todas as chaves de $z$ dentro do nó $y$. O nó $x$ perde $k$ e o ponteiro para $z$. Em seguida, remove-se $k$ de dentro do novo nó $y$.
> 
> 

Exemplo: Remoção da chave `G` 

*Estado anterior: Árvore após a remoção de `M`.*

* **Passo a passo:**
1. A chave `G` está no nó interno `[C, G, L]`.


2. O algoritmo avalia os filhos ao redor de `G`: o da esquerda é `[D, E]` e o da direita é `[J, K]`. Ambos possuem apenas $t-1 = 2$ chaves.


3. Não é possível pegar emprestado de nenhum deles sem violar a regra de chaves mínimas.
4. 
**Intercalação:** O algoritmo desce a chave `G` e une os nós esquerdo e direito, formando um único nó: `[D, E, G, J, K]`.


5. O nó pai agora passa a ser apenas `[C, L]`.


6. Finalmente, `G` é removido do novo nó resultante.





**Resultado:**

```text
               [ P ]
             /       \
       [ C, L ]        [ T, X ]
       /   |   \       /   |   \
  [A,B] [D,E,J,K] [N,O] [Q,R,S] [U,V] [Y,Z]

```

---

## CASO 3A: Descer Emprestado do Irmão

> **Regra:** Se a chave desejada não está no nó atual $x$, precisamos descer para o filho correto $f$. Se $f$ tiver apenas $t-1$ chaves, mas tiver um irmão imediato com pelo menos $t$ chaves, fazemos uma rotação: o pai cede uma chave para $f$, e o irmão com chaves extras cede uma chave para o pai.
> 
> 

Exemplo: Remoção da chave `B` 

Nota de contexto do PDF: Para ilustrar os Casos 3A e 3B, o documento utiliza um estado em que a raiz sofreu modificações prévias e foi unificada em `[C, L, P, T, X]`.

**Árvore de partida para este caso:**

```text
          [ C, L, P, T, X ]
        /   /   |   \   \   \
   [A,B] [E,J,K] [N,O] [Q,R,S] [U,V] [Y,Z]

```

* **Passo a passo:**
1. Queremos remover `B`. O algoritmo começa na raiz `[C, L, P, T, X]` e decide que deve descer para o filho esquerdo `[A, B]`.


2. O nó `[A, B]` possui apenas $t-1=2$ chaves. Não podemos descer para ele diretamente.


3. O algoritmo olha para o irmão imediato à direita: `[E, J, K]`, que possui 3 chaves (pelo menos $t$).


4. **Rotação:** A chave divisória do pai (`C`) desce para o nó `[A, B]`. A menor chave do irmão (`E`) sobe para o lugar de `C` no pai.


5. O nó que ia receber a busca passa de `[A, B]` para `[A, B, C]`. O irmão passa a ser `[J, K]`.


6. Agora que o nó possui chaves suficientes, o algoritmo desce e remove o `B` com segurança (caindo no Caso 1).





**Resultado:**

```text
          [ E, L, P, T, X ]
        /   /   |   \   \   \
   [A,C]  [J,K] [N,O] [Q,R,S] [U,V] [Y,Z]

```

---

## CASO 3B: Descer Intercalando com o Irmão

> **Regra:** Se o filho $f$ tem apenas $t-1$ chaves e todos os seus irmãos imediatos também têm apenas $t-1$ chaves, funde-se $f$ com um de seus irmãos. Isso exige puxar a chave divisória do pai para baixo, movendo-a para dentro do novo nó intercalado.
> 
> 

Exemplo: Remoção da chave `D` 

Para este exemplo, o PDF retorna à estrutura de árvore com o nó pai `[C, L]` e o filho `[D, E, J, K]`.

**Árvore de partida para este caso:**

```text
               [ P ]
             /       \
       [ C, L ]        [ T, X ]
       /   |   \       /   |   \
   [A,B] [D,E,J,K] [N,O] [Q,R,S] [U,V] [Y,Z]

```

* **Passo a passo:**
1. Queremos remover a chave `D` (que não está na raiz `P`).


2. O caminho correto indica descer para o nó esquerdo `[C, L]`. No entanto, `[C, L]` possui apenas $t-1=2$ chaves.


3. O algoritmo verifica o irmão à direita de `[C, L]`, que é `[T, X]`. Ele também possui apenas $t-1=2$ chaves.


4. Como nenhum irmão tem chaves sobressalentes, o Caso 3A não pode ser aplicado.


5. 
**Fusão dos nós internos:** O algoritmo puxa a chave `P` da raiz para baixo e intercala os nós `[C, L]` e `[T, X]` junto com ela, criando um único nó grande: `[C, L, P, T, X]`.


6. A antiga raiz `P` desaparece, diminuindo a altura da árvore em 1 nível.


7. Com a estrutura reorganizada, o algoritmo agora pode descer com segurança até o nó que contém `D` (que agora é o nó `[D, E, J, K]`) e efetuar a exclusão.





**Resultado:**

```text
          [ C, L, P, T, X ]
        /   /   |   \   \   \
   [A,B]  [E,J,K] [N,O] [Q,R,S] [U,V] [Y,Z]

```

> 💡 **Nota Importante:** Os casos **2C** e **3B** são as únicas operações em todo o algoritmo de remoção capazes de diminuir a altura de uma Árvore B.
