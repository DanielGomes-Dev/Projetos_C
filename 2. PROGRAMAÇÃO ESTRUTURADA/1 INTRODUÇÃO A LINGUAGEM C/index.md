# 1. Introdução à Linguagem C

## Resumo
Bloco de fundamentos da linguagem C: sintaxe básica, tipos de dados, operadores, controle de fluxo, funções e regras de escopo. É a base de todo o resto do curso — nada em Gerência de Memória, Strings ou Tipos Abstratos de Dados funciona sem isso consolidado. Ver as subpáginas 1.1–1.8 para o detalhamento de cada tema.

## Onde estudar nos livros
- **[[Livros|K&R]]** — cap. 1 (Uma introdução através de exemplos) a 4 (Funções e estrutura de um programa). Referência principal deste bloco.
- **Celes** — cap. 1 (Conceitos fundamentais) a 4 (Funções) — cobre esse bloco inteiro com profundidade comparável ao K&R (structs ficam no cap. 8, ver 1.2).
