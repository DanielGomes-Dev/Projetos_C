# Teoria - passo a passo — 1.1 Árvores Binárias

Um conceito por arquivo, explicado devagar, com exemplos tirados dos PDFs de aula
(`lista01-EDA/04_Arvores.pdf`, `05_ArvoresBinarias_*.pdf`) e dos livros-base. Ver o guia
completo em [[../../../_modelo-de-explicacao]].

## Ordem de leitura

1. [[Teoria 01 - O que é uma árvore (terminologia)]] — vocabulário geral (raiz, grau, nó
   interno/folha, caminho, nível, altura, floresta).
2. [[Teoria 02 - Árvore binária (definição e notação)]] — definição recursiva, por que
   esquerda ≠ direita, notação textual `<Raiz SAE SAD>`.
3. [[Teoria 03 - Representando e construindo uma árvore binária em C]] — struct, ponteiros,
   `cria`/`inicializa`, construção de baixo para cima.
4. [[Teoria 04 - Percursos em profundidade (pré-ordem, em-ordem, pós-ordem)]] — as três
   ordens de visita e por que cada uma existe.
5. [[Teoria 05 - Percurso em largura, busca e altura]] — percurso com fila, busca força
   bruta O(n), fórmula recursiva de altura.
6. [[Teoria 06 - Tipos de árvore binária (cheia, completa, perfeita)]] — os três formatos
   especiais e por que "completa" importa para heap (módulo 06).
