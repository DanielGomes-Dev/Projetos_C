# 7. Tipos Abstratos de Dados

## Resumo
Um Tipo Abstrato de Dados (TAD) define um conjunto de dados e as operações permitidas sobre eles, separando a **interface** (o quê) da **implementação** (o como). Este é o bloco central do curso: aplica ponteiros/alocação dinâmica ([bloco 2](<../2 GERÊNCIA DE MEMÓRIA/index.md>)) e `struct` ([1.2](<../1 INTRODUÇÃO A LINGUAGEM C/1.2 TIPOS ESTRUTURADOS DE DADOS/index.md>)) para implementar as estruturas de dados lineares clássicas.

## Onde estudar nos livros
- **Celes** — cap. 9 (Tipos Abstratos de Dados) para o conceito; cap. 10 (Listas encadeadas), 11 (Pilhas) e 12 (Filas) para as implementações. Vetores (7.2) e matrizes (7.7) ficam na Parte I, cap. 5 e 6.
- **Szwarcfiter** — cap. 2 (Listas Lineares) — trata alocação sequencial e encadeada, pilhas, filas e listas circulares/duplas no mesmo capítulo, de forma bem sistemática.
- **Cormen** — cap. 10 (Estruturas de Dados Elementares) — pilhas, filas e listas ligadas com análise formal de complexidade das operações.
