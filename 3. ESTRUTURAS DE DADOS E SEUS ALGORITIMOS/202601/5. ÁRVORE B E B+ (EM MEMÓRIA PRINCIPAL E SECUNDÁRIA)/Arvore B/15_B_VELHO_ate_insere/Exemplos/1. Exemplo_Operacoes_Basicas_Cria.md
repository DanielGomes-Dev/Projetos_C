typedef struct arvb{
  int nchaves, folha;
  int *chave;
  struct arvb **filho;
} TARVB;

TARVB* inicializa(void){
  return NULL;
}

//Cria um nó de árvore
TARVB* Cria(int t){
  TARVB *novo = (TARVB *) malloc(sizeof(TARVB));
  novo->nchaves = 0;
  novo->chave = (int *) malloc(sizeof(int) * (2*t-1));
  novo->folha = 1;
  novo->filho = (TARVB **) malloc(sizeof(TARVB *)*2*t);
  int i;
  for(i = 0; i < 2*t; i++)
    novo->filho[i] = NULL;
  return novo;
}

### Explicação Detalhada

A implementação foca na criação de uma estrutura que respeite as propriedades matemáticas de uma Árvore B de grau mínimo $t$.

#### 1. Estrutura do Nó (`TARVB`)

A estrutura define como os dados são organizados na memória:

* **`nchaves`**: Um inteiro que armazena a quantidade atual de chaves presentes naquele nó específico.
* **`folha`**: Um sinalizador (booleano) que indica se o nó é uma folha (onde os ponteiros para filhos são nulos) ou um nó interno.
* **`*chave`**: Um ponteiro para um vetor de inteiros. As chaves devem ser armazenadas em ordem crescente ($ch_1 < ch_2 < \dots < ch_{nchaves}$).
* **`filho`**: Um ponteiro de ponteiro que gerencia o vetor de descendentes. Seguindo a regra da Árvore B, um nó com $n$ chaves possui exatamente $n+1$ ponteiros para filhos.

#### 2. Função `inicializa`

* Simplesmente retorna `NULL` para indicar que a árvore começa vazia, sem nenhum nó alocado.

#### 3. Função `Cria`

Esta função é responsável por alocar dinamicamente o espaço necessário para um novo nó, utilizando o grau mínimo $t$ para definir os limites:

* **Capacidade de Chaves**: Aloca espaço para até $2t - 1$ chaves, que é o limite máximo permitido para qualquer nó na Árvore B.
* **Capacidade de Filhos**: Aloca espaço para até $2t$ ponteiros de filhos.
* **Inicialização**:
* O número de chaves inicia em 0.
* O nó é marcado inicialmente como folha (`folha = 1`).
* Um laço `for` garante que todos os ponteiros de filhos recém-alocados comecem apontando para `NULL`, evitando lixo de memória.



Essa estrutura é a base para os **algoritmos de "uma passagem"** (preemptivos), que realizam operações de busca e inserção de forma descendente, corrigindo a árvore (como divisões de nós cheios) antes que problemas de transbordamento ocorram.
