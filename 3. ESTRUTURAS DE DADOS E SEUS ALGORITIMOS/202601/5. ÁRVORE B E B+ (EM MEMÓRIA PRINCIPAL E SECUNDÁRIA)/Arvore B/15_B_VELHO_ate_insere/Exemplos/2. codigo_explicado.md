### Passo a Passo Detalhado e Resolução Baseada no Texto

Vamos fatiar o código e aplicar os Pilares da Rastreabilidade e Simetria.

#### 1. Inicialização e Criação do Nó

```c
TARVB *TARVB_Inicializa(){
  return NULL;
}

TARVB *TARVB_Cria(int t){
  TARVB* novo = (TARVB*)malloc(sizeof(TARVB));
  novo->nchaves = 0;
  novo->chave =(int*)malloc(sizeof(int*)*((t*2)-1));
  novo->folha=1;
  novo->filho = (TARVB**)malloc(sizeof(TARVB*)*t*2);
  int i;
  for(i = 0; i < (t*2); i++) novo->filho[i] = NULL;
  return novo;
}

```

* **Resolução pelo Texto:** O texto define que existem "limites inferiores e superiores expressos em termos de um inteiro $t$, $t \ge 2$". Todo nó tem no máximo $2t - 1$ chaves e $2t$ filhos.
* **Rastreabilidade de Unidades:** A função `TARVB_Cria` materializa essa regra na memória. Ela aloca espaço exato para `(2*t)-1` chaves (array de `int`) e `2*t` ponteiros para os filhos.
* **Anatomia do Passo:** Garantimos a integridade inicial setando `nchaves = 0` e `folha = 1` (todo novo nó nasce como folha até ganhar filhos). Todos os ponteiros são zerados (`NULL`) no laço `for` para evitar lixo de memória.

#### 2. Liberação e Impressão (Algoritmos de Travessia)

```c
TARVB *TARVB_Libera(TARVB *a){
  if(a){
    if(!a->folha){
      int i;
      for(i = 0; i <= a->nchaves; i++) TARVB_Libera(a->filho[i]);
    }
    free(a->chave);
    free(a->filho);
    free(a);
    return NULL;
  }
}

```

* **Anatomia do Passo (Liberação):** Esta é uma travessia pós-ordem. **Não** podemos liberar a casca do nó (seus arrays) antes de liberar seus filhos, senão perdemos os ponteiros (Pilar da Simetria: libere o conteúdo antes do contêiner). Se `!a->folha`, descemos recursivamente em todos os filhos lógicos (`0` até `nchaves`). Só então aplicamos o `free` nas chaves, nos filhos e na estrutura.

*(Nota: As funções `imp_rec`, `TARVB_Imprime`, `imp_rec2` e `TARVB_Imprime2` seguem a mesma lógica de travessia, intercalando a chamada recursiva aos filhos com a impressão das chaves simulando níveis de profundidade com o caractere de tabulação `\t`).*

#### 3. A Busca

```c
TARVB *TARVB_Busca(TARVB* x, int ch){
  if(!x) return NULL;
  int i = 0;
  while(i < x->nchaves && ch > x->chave[i]) i++;
  if(i < x->nchaves && ch == x->chave[i]) return x;
  if(x->folha) return NULL;
  return TARVB_Busca(x->filho[i], ch);
}

```

* **Resolução pelo Texto:** "As chaves de um nó separam os intervalos de chaves que podem ser armazenadas em cada subárvore".
* **Rastreabilidade:** O laço `while` é uma varredura linear. Ele procura a primeira chave que seja maior ou igual a `ch`.
* **Justificação de Ajuste:** Se achou a chave (`ch == x->chave[i]`), retorna o nó atual. Se a varredura esbarrou no final das chaves ou encontrou uma chave maior e o nó é `folha`, a chave não existe na árvore (retorna `NULL`). Caso contrário, desce no filho da subárvore correspondente: `x->filho[i]`.

#### 4. O Coração da Árvore: Divisão de um Nó Completo

```c
TARVB *Divisao(TARVB *x, int i, TARVB* y, int t){
  TARVB *z=TARVB_Cria(t);
  z->nchaves= t - 1;
  z->folha = y->folha;
  int j;
  for(j=0;j<t-1;j++) z->chave[j] = y->chave[j+t];
  if(!y->folha){
    for(j=0;j<t;j++){
      z->filho[j] = y->filho[j+t];
      y->filho[j+t] = NULL;
    }
  }
  y->nchaves = t-1;
  // ... (ajustes no nó pai x)

```

* **Resolução pelo Texto:** "Dividir um nó $y$ completo ao redor da chave $t$, em dois nós com $t - 1$ chaves. A chave $t$ (mediana) desloca-se para o pai".
* **Pilar da Simetria:** Aqui vemos a conservação da massa. O nó $y$ tem $2t - 1$ chaves. Criamos o nó $z$. O primeiro laço `for` copia as últimas $t-1$ chaves de $y$ para $z$. O segundo laço copia os últimos $t$ ponteiros de filhos de $y$ para $z$. O nó original $y$ sofre um "corte lógico", e passa a assumir que só possui $t-1$ chaves (`y->nchaves = t-1`).

```c
  // ... (continuação de Divisao)
  for(j=x->nchaves; j>=i; j--) x->filho[j+1]=x->filho[j];
  x->filho[i+1] = z; // Correção conceitual: no código está x->filho[i]=z, mas ajusta-se conforme a posição
  for(j=x->nchaves; j>=i; j--) x->chave[j] = x->chave[j-1];
  x->chave[i-1] = y->chave[t-1];
  x->nchaves++;
  return x;
}

```

* **Justificação de Ajuste no Pai ($x$):** O preço de fatiar o filho $y$ é que o pai $x$ precisa absorver a chave mediana e apontar para o novo filho $z$. Para isso, empurramos todos os filhos de $x$ uma casa para a direita para abrir um "buraco" para $z$. Em seguida, empurramos as chaves de $x$ para a direita para abrir espaço para a chave `y->chave[t-1]`. Por fim, somamos `x->nchaves++`.

#### 5. Inserção Preemptiva: Nó Não Completo

```c
TARVB *Insere_Nao_Completo(TARVB *x, int k, int t){
  int i = x->nchaves-1;
  if(x->folha){
    while((i>=0) && (k<x->chave[i])){
      x->chave[i+1] = x->chave[i];
      i--;
    }
    x->chave[i+1] = k;
    x->nchaves++;
    return x;
  }

```

* **Resolução pelo Texto:** "À medida que se desce na árvore à procura pela folha, divide-se cada nó completo encontrado".
* **Anatomia do Passo:** Se o nó é folha (caso base), procuramos o espaço da chave `k` movendo todas as chaves maiores que `k` uma posição para a direita (`x->chave[i+1] = x->chave[i]`). Inserimos `k` e aumentamos `nchaves`. Sabemos que isso não causará *overflow* porque a função de divisão garantiu que este nó tem espaço.

```c
  // (continuação: se não for folha)
  while((i>=0) && (k<x->chave[i])) i--;
  i++;
  if(x->filho[i]->nchaves == ((2*t)-1)){
    x = Divisao(x, (i+1), x->filho[i], t);
    if(k>x->chave[i]) i++;
  }
  x->filho[i] = Insere_Nao_Completo(x->filho[i], k, t);
  return x;
}

```

* **Pilar da Rastreabilidade:** Procuramos o filho exato onde `k` deve descer. **A Regra de Ouro do Algoritmo Preemptivo atua aqui:** Antes de descer (`x->filho[i] = Insere_Nao_Completo(...)`), olhamos para o filho. Se ele já estiver estourando (`nchaves == 2t-1`), nós o estouramos ativamente usando `Divisao()`. Ao dividir, a chave central do filho sobe. Precisamos reavaliar se `k` deve descer pelo irmão da esquerda ou da direita (`if(k>x->chave[i]) i++;`), e então prosseguimos a descida em segurança.

#### 6. A Casca da Inserção (Proteção da Raiz)

```c
TARVB *TARVB_Insere(TARVB *T, int k, int t){
  if(TARVB_Busca(T,k)) return T;
  if(!T){
    T=TARVB_Cria(t);
    T->chave[0] = k;
    T->nchaves=1;
    return T;
  }
  if(T->nchaves == (2*t)-1){
    TARVB *S = TARVB_Cria(t);
    S->nchaves=0;
    S->folha = 0;
    S->filho[0] = T;
    S = Divisao(S,1,T,t);
    S = Insere_Nao_Completo(S,k,t);
    return S;
  }
  T = Insere_Nao_Completo(T,k,t);
  return T;
}

```

* **Resolução pelo Texto:** "Para a raiz completa: Transforma a raiz em um filho de um nó raiz vazio para usar o algoritmo de divisão; SOMENTE dessa maneira a árvore cresce uma unidade em altura."
* **Anatomia do Passo:** 1. Se a árvore está vazia, cria-se a raiz folha.
2. A grande manobra preventiva: Se a raiz atual `T` atingiu a carga máxima (`2t-1`), a árvore **vai crescer para cima**.
3. Criamos uma nova raiz falsa `S`, que nasce vazia e estéril (`S->folha = 0`), e forçamos a velha raiz completa `T` a ser o primeiro filho de `S` (`S->filho[0] = T`).
4. Executamos a `Divisao` em `S` quebrando `T`. `S` absorve a chave mediana e vira a verdadeira nova raiz, ganhando altura $h+1$.
5. Após garantir que a porta de entrada não está entupida, chamamos `Insere_Nao_Completo` para deixar a chave `k` escorregar até a folha correta.

### Conclusão e Resultado

A junção destas funções representa fielmente o conceito do **algoritmo preemptivo de uma passagem** citado no texto. Ele troca a complexidade de ter que gerenciar pilhas de retornos recursivos para consertar a árvore de baixo para cima, pela antecipação proativa: dividimos enquanto descemos, garantindo que o caminho à frente tenha sempre espaço para absorver uma nova variável, pagando o "preço matemático" de apenas realocar índices em arrays ordenados.
