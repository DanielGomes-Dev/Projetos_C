# 1.2 Tipos Estruturados de Dados

## Resumo
Tipos compostos a partir dos primitivos: vetores (`arrays`, coleção homogênea de tamanho fixo), `struct` (registros — agrupam campos de tipos diferentes sob um nome), `union` (compartilham o mesmo espaço de memória entre campos) e `enum` (conjuntos nomeados de constantes inteiras). Base necessária antes de Tipos Abstratos de Dados (bloco 7), que usa `struct` para modelar nós de listas/pilhas/filas.

## Onde estudar
- **K&R** — cap. 6 (Estruturas) para `struct`/`union`; cap. 1 e 5 para vetores.
- **Celes** — cap. 8 ("Tipos estruturados"), capítulo dedicado a `struct`/`typedef` (com exemplo condutor `struct ponto`); `union`/`enum` não apareceram de forma legível na extração OCR do livro.

- [ ] Diferenciar `struct` de `union`
